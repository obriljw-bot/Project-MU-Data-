# Grip 채팅 리바운더(Chat Rebounder) 개발 기획안

## 1. 개요 (Overview)
**Grip 라이브 커머스** 방송 중 발생하는 채팅을 실시간으로 모니터링하여, 특정 키워드가 감지될 때 자동으로 답변을 발송하고 통계를 수집하는 자동화 프로그램을 개발합니다.

## 2. 개발 방식 (Technical Approach)
사용자의 요구사항인 "화면 인식" 및 "텍스트 인식"을 가장 정확하고 안정적으로 구현하기 위해 **웹 브라우저 자동화(Web Automation)** 방식을 채택합니다.

-   **플랫폼**: PC 웹 브라우저 (Chrome/Edge)
-   **핵심 기술**:
    -   **Node.js**: 프로그램 구동 환경
    -   **Playwright**: 브라우저 제어 및 웹페이지 조작 라이브러리 (MS에서 개발, 안정성 우수)
    -   **DOM Monitoring**: 화면의 픽셀을 분석하는 OCR(광학 문자 인식) 방식 대신, 웹페이지의 소스 코드(DOM) 변화를 실시간으로 감지하여 텍스트를 100% 정확하게 추출합니다.

### 2.1 선정 이유
1.  **정확도**: OCR 방식은 배경색, 글자 겹침, 해상도에 따라 인식률이 떨어지지만, DOM 추출 방식은 오타 없이 100% 정확한 텍스트를 가져올 수 있습니다.
2.  **속도**: 이미지를 캡쳐하고 분석하는 과정이 없으므로, 채팅이 올라오는 즉시(0.1초 이내) 반응할 수 있습니다.
3.  **유지보수**: Grip 웹페이지 구조가 크게 바뀌지 않는 한 안정적으로 동작합니다.

## 3. 주요 기능 (Features)

### A. 실시간 방송 모니터링 및 스니퍼 봇 연동
-   지정된 Grip 방송 URL에 은밀히 접속하여 실시간 채팅 및 시스템 이벤트를 감시합니다. (`signal_sniffer_v3.js`)
-   **MutationObserver** 기술을 바탕으로 채팅 배열 뿐만 아니라 `선착순 O명 당첨`, `장바구니 담겼어요` 같은 시스템 UI 알림도 캐치합니다.

### B. 스마트 응답 및 판매자 프롬프터 (Prompter)
-   **자동 응답 (Auto-Reply)**: "얼마", "배송", "사이즈" 등 특정 키워드에 대해 방송 관리자가 설정한 텍스트로 보조 봇이 실시간 채팅 답변을 달아줍니다.
-   **판매자 프롬프터 (Overlay)**: 방송 웹 화면 좌측 상단에 오버레이 패널을 띄워, 판매자가 방송 중 봐야 할 **'메인 상품 정보/재고/실시간 큐사인'** 을 전송합니다.

### C. 실시간 판매 체결 로그 및 자동 재고 집계 (V4.0 ~ 4.1)
-   방장이 "선착순" 이벤트를 진행할 때, 봇이 당첨자 수를 파악하고 장바구니에 담긴 **제품 코드**를 자동 추출합니다.
-   추출된 이벤트는 대시보드 하단의 **'판매 체결 로그(Completed Sales)'** 패널에 영구 기록됩니다.
-   관리자는 해당 로그를 확인한 후 `[일괄 갱신]` 또는 개별 `[적용하기]` 버튼을 눌러, 상품 테이블의 **'실시간 판매량(Sold)' 및 '매출액(Revenue)'** 을 원클릭으로 합산시킵니다.
-   동일 이벤트가 중복 합산되지 않도록 0.5초 단위 초정밀 Debounce 필터가 적용되어 있습니다.

### D. 실시간 핫키워드 및 반응 분석 (V4.2)
-   방송 중 올라오는 채팅들을 실시간으로 분석하여 **1번 이상** 등장한 의미 있는 단어들만 솎아내어 우측 랭킹 차트에 표시합니다.
-   **Query (질문)**: 배송, 재고, 가격 등 봇이나 판매자가 반응해야 할 질문성 채팅 키워드
-   **Reaction (반응)**: 환호성이나 일반적인 호응 채팅 키워드
-   채팅 트렌드 분석은 브라우저 렌더링 엔진에서 0.1초 단위로 화면에 즉각 갱신됩니다.

## 4. 개발 로드맵 (Roadmap)
1.  **환경 설정**: Node.js 프로젝트 생성 및 Playwright 설치
2.  **프로토타입 (POC)**:
    -   Grip 로그인 및 방송 입장 자동화
    -   채팅 텍스트 실시간 로그 출력 테스트
3.  **핵심 기능 구현**:
    -   키워드 매칭 로직
    -   자동 응답 전송 기능
4.  **안전장치 추가**:
    -   **도배 방지 (Rate Limiting)**: 동일한 사람에게 연속 답변 금지, 전체 답변 간격(쿨타임) 설정.
    -   **자가 루프 방지**: 내 계정이 보낸 메시지에는 반응하지 않음.
5.  **테스트 및 배포**: 실제 방송 환경 테스트 진행.

## 5. 사용자 준비 사항
-   Grip 방송을 모니터링할 **계정** (매니저 계정 또는 부계정 권장)
-   PC 환경 (Windows/Mac)
